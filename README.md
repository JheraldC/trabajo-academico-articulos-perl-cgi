# Trabajo académico: gestión de artículos con Perl CGI

Aplicación académica con páginas web y scripts de servidor para gestionar artículos y operaciones de usuarios.

## Capacidades técnicas

HTML, CSS, JavaScript, Perl CGI, DBI y acceso a MariaDB mediante consultas preparadas.

## Contenido

- [trabajofinal](trabajofinal): frontend.
- [segundofinal](segundofinal): scripts de creación, consulta, actualización, eliminación y acceso de usuarios.

## Uso

Requiere un servidor con CGI, Perl y los módulos CGI, DBI y el controlador de MariaDB. Revisar la conexión local definida en los scripts y preparar el esquema que esperan. El repositorio no ofrece una instalación completa del servidor ni un esquema de base de datos documentado. Un servidor estático no ejecuta los scripts Perl.

## Alcance

Trabajo académico con configuración histórica de laboratorio. La [primera entrega](https://github.com/JheraldC/trabajo-academico-web-perl-cgi-avance) se conserva como antecedente.

El repositorio conserva un ejercicio académico. La documentación describe el uso previsto; no certifica una ejecución reciente ni resultados de rendimiento.
